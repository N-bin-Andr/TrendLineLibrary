# Changelog

## [Unreleased]
### Added
- Базовый класс TrendLineObject
- Свойства для настройки линии (цвет, толщина, стиль)
- Свойства для настройки текста
- Поддержка удлинения концов (влево/вправо)
- Контрольные точки для редактирования
- Исследовательский код для DataProvider API

- Улучшена система отрисовки текста с фоном

### Fixed
- Исправлена инициализация свойств в конструкторе
- Добавлена проверка границ для LineWidth и FontSize
